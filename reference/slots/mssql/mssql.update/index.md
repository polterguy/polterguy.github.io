`mssql.update` is a slot in the `mssql` namespace, in Hyperlambda, the language of Magic Cloud. Updates rows through the current SQL Server connection; use [where] to constrain affected rows.

* **Returns**: Resolves to the number of rows affected
* **Scope**: requires `mssql.connection` - Requires an open SQL Server connection created by [mssql.connect]

`function` is an alias of [`slots.create`](/reference/slots/slots/slots.create/) in Hyperlambda, the language of Magic Cloud, with exactly the same contract. Creates a dynamic slot that can be invoked with [signal].

See [`slots.create`](/reference/slots/slots/slots.create/) for its value, arguments, constraints and return value.

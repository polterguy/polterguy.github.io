This is the guide to [`git.fetch`](/reference/slots/git/git.fetch/), whose reference page has its arguments, constraints and declaration.

Fetches updates from a remote. The repo path is the node value. The `remote` child node defaults to `origin`.

```
git.fetch:/modules/stripe/
```

```
git.fetch:/modules/stripe/
   remote:origin
   refspec:main
```

The reference page of [`strings.starts-with`](/reference/slots/strings/strings.starts-with/) has its arguments, constraints and declaration.

Returns true if the specified string starts with some sequence of characters.

```
// Returns true
strings.starts-with:Thomas Hansen Is Cool
   .:Thomas

// Returns false
strings.starts-with:Thomas Hansen Is Cool
   .:Hansen
```

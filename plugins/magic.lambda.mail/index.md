This project contains SMTP and POP3 helpers for Magic. More specifically, this project contains the following slots.

* __[\[mail.smtp.send\]](/reference/slots/mail/mail.smtp.send/)__ - Sends email(s) through an SMTP server
* __[\[mail.pop3.fetch\]](/reference/slots/mail/mail.pop3.fetch/)__ - Retrieves emails from a POP3 server

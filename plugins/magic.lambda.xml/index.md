This project provides XML helper slots for Hyperlambda. More specifically, it provides the following slots.

* __[\[xml2lambda\]](/reference/slots/core/xml2lambda/)__ - Creates a lambda object out of an XML input string
* __[\[lambda2xml\]](/reference/slots/core/lambda2xml/)__ - Creates an XML string from a lambda object

This project provides PDF slots for Magic. The project provides the following
slots, allowing you to convert a PDF file, stream or raw bytes to its text representation.

* __[\[pdf2text\]](/reference/slots/core/pdf2text/)__ - Converts the specified PDF file or stream to text
* __[\[html2pdf\]](/reference/slots/core/html2pdf/)__ - Converts HTML into a PDF document

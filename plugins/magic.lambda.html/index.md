This project provides HTML helper slots for Magic. More specifically, it provides the following slots.

* __[\[html2lambda\]](/reference/slots/core/html2lambda/)__ - Creates a lambda object out of an HTML input string.
* __[\[lambda2html\]](/reference/slots/core/lambda2html/)__ - Creates an HTML string out of the specified lambda object.
* __[\[markdown2html\]](/reference/slots/core/markdown2html/)__ - Creates HTML out of the specified Markdown input string.
* __[\[html2markdown\]](/reference/slots/core/html2markdown/)__ - Creates Markdown out of the specified HTML input string.
* __[\[html-decode\]](/reference/slots/core/html-decode/)__ - HTML decodes the specified string.
